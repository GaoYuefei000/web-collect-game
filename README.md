# web-collect-game
PC+移动端双端网页收集小游戏，Canvas原生绘制，单HTML文件直接运行。

## ✨ 游戏特色
- 3档难度选择：简单 / 普通 / 困难
- 吃到黄色豆子**永久提升玩家移速**（有速度上限，防止失控）
- 得分越高，幽灵敌人移动速度越快，难度动态递增
- 电脑端：方向键 ↑↓←→ 控制
- 手机端：屏幕虚拟方向按钮触屏游玩
- 自带音效（拾取豆子、碰撞结束）
- 游戏结束面板显示得分与难度，支持重新开局

## 🚀 运行方式
方法1：本地游玩
1. 下载 `index.html`
2. 双击文件，使用浏览器打开即可直接游玩

方法2：在线游玩
开启GitHub Pages后访问项目网页链接。
